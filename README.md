# VIP Gifts — site pentru GitHub Pages

Acest folder conține direct site-ul: index.html, script.js, scene.js, style.css, editorial.css, assets/ și ru/.

## Publicare fără comenzi în terminal

1. Creează un repository public în contul tău GitHub, de exemplu vip-gifts. Bifează Add a README file la creare, pentru a porni ramura main.
2. În repository, alege Add file → Upload files.
3. Încarcă tot CONȚINUTUL acestui folder, astfel încât index.html să fie direct la rădăcina repository-ului. Nu încărca arhiva ZIP.
4. Salvează încărcarea cu butonul Commit changes sau Propose changes, conform interfeței afișate.
5. În Settings → Pages, la Source selectează Deploy from a branch. Alege main și /(root), apoi Save.
6. Așteaptă finalizarea publicării. Adresa apare în Settings → Pages și are forma https://NUMELE-TAU.github.io/vip-gifts/.

Nu sunt necesare npm, baze de date sau chei API. Modelele 3D, imaginile și fonturile sunt incluse și servite local. Prețurile sunt afișate ca MDL, fără valori inventate. Comenzile sunt continuate pe Instagram.

Versiunea rusă se află la ru/. Căile au fost adaptate pentru publicarea site-ului într-un repository de proiect, inclusiv dacă numele repository-ului diferă de vip-gifts.

Modelele 3D sunt orientative. Imaginea de studio a fost realizată cu ImageGen pornind de la fotografia VIP Gifts. Fotografiile din catalog sunt din materialele furnizate.
